| `npm run stranger` | Live. Fetches 3 recent transactions by id from the indexer, parses them with the page's own code, checks the real bytes and that a key that fits nothing hears nothing. On a quiet chain it checks the ones it found and says "quiet chain: N of 3" (exit 0), or SKIP when it found none (exit 0), and it writes `evidence/stranger-recent.txt` only when all 3 were found and passed. (It used to look at the latest 40 only, and on 2026-10-24 it stopped with "only 0 recent transactions with private transfers were found (wanted 3)" and, later that day, with "only 2".) `node scripts/stranger.mjs <id> ...` checks the ids you name |

Summon making one request, for the list, and none for an id; an id found in that list asking for nothing; a demo id asked for by id; an id outside the list getting one line and two buttons and no request by id until "Ask for it anyway", which asks exactly once and shows the real indexer's "not found"; the ghost log listing the requests the page made as the debugging protocol saw them (the browser's own refresh of its saved list is counted apart), every row saying what its host learns, the headline counting them (and K, the requests that name a transaction id, worked out again from the addresses the debugging protocol saw), and no key in any of them; | `npm run links` | About 95 plain requests, one at a time (no polling), and one headless page. **Changed on 2026-10-29: it checks receipts, not whole transactions.** The second public indexer used to return a whole transaction by id and this check compared it with `ledger.json`; that day it began to answer 404 for that (for all 20 ids), while both indexers still answer 200 at `/transaction-receipts/<id>`, so the check was moved to the receipts. For each of the 20 transactions (the 15 demos, the 3 set-up steps and the 2 of the recorded sample that Summon falls back to), both public indexers must answer 200 at `/transaction-receipts/<id>` with outcome Commit. For the 17 that have a saved copy in `ledger.json` (the 3 set-up steps have none, so for them only the answer and the outcome are checked), each receipt must also agree with it on every field the two carry, measured on that day: the outcome (`summary.outcome` and the receipt's `outcome`); the fee paid (`summary.total_fees_paid` and `fee_receipt.total_fees_paid`); the sealed notes the transaction spent (the `utxo_` ids among the saved inputs, and the `utxo_` ids in `diff_summary.downed`, as sets; the other inputs, a component, a vault and the token, are updated, not spent, so they are not in `downed`); and the epoch, a bound rather than an equal field (the receipt's `epoch` inside the saved transaction's `min_epoch` to `max_epoch`). A receipt holds no transaction id, so an id is tied to its receipt only by the address it was fetched from; the saved inputs hold no version (null), so versions are not compared. This is weaker than the old check, which compared the whole answer: the sealed bytes and memos in `ledger.json` are no longer compared with any public answer. Reported, not judged: whether the two receipts are identical (they were for all 20 on 2026-10-29), and what each indexer says for the whole transaction by id (404 on both that day). Also: the demo token's template and token record on both indexers (its view key must be the audit key), the explorer's page for the token (headless: it must list that View key), the links to the explorer and to ootle.tari.com, and two negative controls: a made-up id must get 404 at the receipt address of both indexers, and the comparison must disagree when it is given another transaction's receipt. The links that exist only once this repository is published (the ledger on raw.githubusercontent.com, the template file on GitHub, the badge, the Pages address and the images under `media/`) are checked too, marked in the output and counted apart in the result: they can only pass after the first push. **Depends on what the testnet holds today:** it fails if an indexer drops the receipts too. The comparison is tested offline in `test/receipts.test.ts`, against the 20 receipts recorded on 2026-10-29 (`test/fixtures/receipts.json`). Writes `evidence/links.txt` |
