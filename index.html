The Auditor

Holds a token's audit key. Counts the amounts. Cannot spend, cannot read a memo.

Whose key does the auditor hold?

An audit key belongs to the token, not to a person. The token's maker names it once, and from then on every note of the token carries a proof that only that key opens. The demo key is public on purpose, for testnet only.

How this token was made: of Rust

The token's maker names the audit key once, in the line .with_view_key(auditor). That is all it takes: from then on every note of the token carries a proof that only that key opens. Anyone may mint this token, which is fine for a testnet toy.

The Poltergeist

A ghost with no keys at all, only patience. It reads what a stranger can read and asks one question of the demo payments: were they all sent by the same wallet? It tries four tricks, and one extra, on two ledgers.

The transparent ledger is synthetic. It is not a real chain. This page builds it from the same payments, with the sender, the receiver and the amount written in the open, the way an account ledger does. The times, epoch windows and fees are the real ones. It holds only these payments.

Testnet only. Every transaction here lives on Tari's Esmeralda test network. The demo view keys, the audit key included, are public on purpose and unlock nothing else. Never reuse them.
